Structure of android/
======================

The Android source tree is a Gradle build dependent on ../java/
(the companion pure-Java library code).  The two are linked by a
Gradle *composite build*: settings.gradle.kts here does:

    includeBuild("../java")

which pulls java/'s subprojects (libdraw, libexpr, libflow) in.
app/build.gradle.kts then declares:

    implementation("org.rapidcow.trivnote:libexpr")

etc. and Gradle substitutes in the real ../java/libexpr project at build
time.  (The Maven coordinate works because each java/*/build.gradle.kts
declares `group = "org.rapidcow.trivnote"'.)

As of now, the souce tree takes on the following topology:

android/
├── gradlew, gradlew.bat          Gradle wrapper launcher scripts.
├── gradle/
│   ├── wrapper/
│   │   ├── gradle-wrapper.jar
│   │   └── gradle-wrapper.properties   Pins the exact Gradle version
│   │                                   (currently 9.6.0) this project
│   │                                   builds with, so every machine
│   │                                   uses the same Gradle regardless
│   │                                   of what's installed globally.
│   ├── libs.versions.toml        Version catalog: single source of
│   │                              truth for AGP / Kotlin / Compose /
│   │                              AndroidX dependency versions, referenced
│   │                              from build.gradle.kts files as
│   │                              `libs.foo` / `libs.plugins.bar`.
│   └── gradle-daemon-jvm.properties   Pins the JVM toolchain (currently
│                                       25) the Gradle *daemon* process
│                                       itself runs on. Auto-provisioned
│                                       via the foojay-resolver plugin
│                                       declared in settings.gradle.kts
│                                       if not already installed locally.
│
├── settings.gradle.kts           rootProject.name = "trivnote";
│                                  include(":app"); includeBuild("../java")
│                                  -- the composite-build link described above.
│
├── build.gradle.kts              Root/top-level build file: just declares
│                                  which plugins (android-application,
│                                  kotlin-compose) are available to
│                                  subprojects, applied per-module below.
│
├── gradle.properties              Project-wide Gradle settings (JVM args,
│                                   AndroidX flags, etc).
│
├── local.properties                           *** IMPORTANT! ***
│                                   Local settings.
│                                   For example, it may contain the line:
│                                       sdk.dir=/opt/android-sdk
│                                   telling Gradle/AGP where the Android
│                                   SDK lives on the current host.  (Android Studio
│                                   normally writes this file; create as needed.)
│
├── .gitignore                     Standard Android ignores: build/,
│                                   .gradle/, local.properties (x2,
│                                   harmlessly redundant), *.iml, plus a
│                                   partial .idea/ ignore (shares
│                                   project-level IDE config like vcs.xml,
│                                   misc.xml; ignores per-user state like
│                                   workspace.xml).
│
└── app/                           The Android application module.
    ├── build.gradle.kts            Same function as the build.gradle.kts's
    │                               in ../ and in ../../java/.
    └── src/
        ├── main/
        │   ├── AndroidManifest.xml     Single launcher Activity
        │   │                            (.MainActivity).
        │   ├── java/org/rapidcow/android/trivnote/
        │   │   ├── MainActivity.kt     Entry point idk
        │   │   └── ui/theme/
        │   │       ├── Color.kt
        │   │       ├── Theme.kt
        │   │       └── Type.kt         Stock Compose Material3 theme.
        │   ├── res/                    Standard Android resources: launcher
        │   │   │                        icons at every density + adaptive
        │   │   │                        icon XML, background/foreground
        │   │   │                        drawables, values/ (colors,
        │   │   │                        strings, themes), xml/ (Android
        │   │   │                        12+ backup + data-extraction rules).
        │   │   └── ...
        │   └── keepRules/rules.keep    R8/ProGuard keep rules.
        ├── test/java/.../ExampleUnitTest.kt          Stock JVM unit test.
        └── androidTest/java/.../ExampleInstrumentedTest.kt
                                                        Stock on-device test.


Proxy note (for GFW censorship bypass)
---------------------------------------

Gradle does NOT read the HTTP_PROXY / HTTPS_PROXY environment variables --
it only honors JVM system properties.  For that, edit:

    ~/.gradle/gradle.properties

with the lines:

    systemProp.http.proxyHost=127.0.0.1
    systemProp.http.proxyPort=7890
    systemProp.https.proxyHost=127.0.0.1
    systemProp.https.proxyPort=7890

(These are taken from the same file generated by Android Studio
on the nucbox (the host that generated these boilerplate files.))
